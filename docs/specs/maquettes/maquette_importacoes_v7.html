Estrutura, vocabulário e adaptador ortogonal ao circuito
Adaptador resolvido : UNIMARC · ISO 2709 → book_drafts combinação sem adaptador → mapeamento manual

A « foultitude » de formatos se decompõe em três planos : a estrutura (o contêiner — ISO 2709, XML, JSON, tabular…), o vocabulário (o sentido dos campos — UNIMARC, MARC21, Dublin Core, Zotero/CSL, BibTeX…) e o modelo conceitual (as entidades). AnarBib tem o seu modelo : todo adaptador mapeia para book_drafts, não reproduz o da fonte. Um adaptador = decodificador de estrutura + mapeador de vocabulário. Campos descritivos → colunas de book_drafts ; pontos de acesso (autor, assunto) → autoridades, nunca texto livre. Vindo de « Fontes externas », a derivação exige uma passagem de limpeza (retirar os identificadores locais da fonte, re-apontar as autoridades) — é a própria fila de revisão. Novo formato = novo adaptador (muitas vezes só uma nova combinação já conhecida) + perfil reutilizável — não uma nova aba ; o mesmo registro serializa na saída. Horizonte : dados ligados (BIBFRAME) = mais um adaptador, mesma arquitetura.

Fontes externas companheiras + institucionais

Dois planos distintos, deliberadamente. Bibliotecas companheiras : uma relação que se constrói (identificação → contato → acordo → federação) ; a importação só abre por consentimento, e pode um dia levar à integração na rede AnarBib. Fontes institucionais : utilidades de metadados (catalogação por cópia, atribuição) — sem reciprocidade, sem mutualização.

Exportar = partilhar para fora. O que sai é governado pelos mesmos sinais (mutualize_allowed…) e pelo perímetro ILL : material cinza e domínio público sim, obras comerciais (ISBN/ISSN) não. ILL-1..3 · ILL-9
Partilha de documento #ILL-digital · spec ILL-1..9 (a codar)

Uma biblioteca federada pede a digitalização de um documento que só você detém. Fluxo curto, sem retorno de objeto — não é um PEB.

Entre bibliotecas federadas (library_partnerships) com o direito digital_share ativo — não com os coletivos catalog_partners (CIRA, Pinelli…), que saem deste circuito (PARTNER-D6).

Plafond de difusão (ILL-3/ILL-9) : cada documento carrega um teto public/staff_only que viaja com ele. A fonte nunca exporta mais aberto do que ela mesma assume ; o receptor pode endurecer, nunca afrouxar ; travado em base + dupla marca temporal. Nenhum caminho torna um documento mais público ao circular.

Meio-cadeado ISBN/ISSN (ILL-2) : sinaliza e orienta ao PEB ; se o documento já figura num catálogo da rede, o export é bloqueado. Modo pontual (padrão, ILL-4) : nenhuma cópia no receptor — URL assinada de TTL curto no ProtectedMediaViewer, sem download. Versamento durável só para livres de direitos, que entram no catálogo (ILL-5).

A fonte conserva o patrimônio ; o auditável é « pedido satisfeito », não a cópia (ILL-6). Condições cumuladas : parceria ativa ∧ digital_share ∧ plafond compatível (ILL-8).
