# Hébergeurs Jitsi militants / libres — candidats pour la visio d'entraide AnarBib

> **Document de préparation à une démarche HUMAINE** (présentation d'AnarBib +
> demande d'hébergement). Date de vérification web : **2026-06-16**.
> Recherche menée depuis la session « Fédération — Communs & Entraide ».
>
> ⚠️ **Les instances Jitsi apparaissent et disparaissent.** Les statuts ci-dessous
> sont vérifiés au 16/06/2026 ; **re-confirmer avant chaque prise de contact.**
>
> Côté technique : la bascule se fait par **une seule variable de build**
> (`VITE_JITSI_DOMAIN`, défaut `meet.jit.si`) — aucun changement de code le jour
> où un collectif accepte. Salle = `anarbib-entraide-<uuid de l'appel>` (non
> devinable). On reste simple **client** d'une instance : zéro coût, zéro secret
> côté hôte au-delà de faire tourner Jitsi.

---

## Pourquoi cette démarche

Par défaut la visio pointe sur `meet.jit.si` (instance publique de l'éditeur,
gérée par 8x8). Ça fonctionne, mais ce n'est ni militant ni autonome. On cherche
un **collectif ami** (anticapitaliste, féministe, libriste solidaire) qui
accepterait d'héberger nos salles, idéalement **lusophone** (la base du réseau
est brésilienne — BTL), ou à défaut dans une des langues du réseau.

Argumentaire à porter : AnarBib est un SIGB **libre (AGPL-3.0)**, autogéré, sans
budget, au service d'un réseau de ~368 bibliothèques anarchistes. La charge Jitsi
est **faible et ponctuelle** (entraide entre bibliothécaires, petits groupes,
pas de webinaires de masse).

## TIER 1 — Lusophone + militant (PRIORITÉ, base brésilienne BTL)

### 1. Vedetas / MariaLab 🇧🇷 — ✅ actif (à confirmer le périmètre)
- **Qui** : MariaLab (`marialab.org`), collectif tech **féministe** brésilien
  (fondé 2014), pôle « Infraestrutura Feminista ». Maintient la serveuse
  **Vedetas** (`vedetas.org`) et le projet Maria Vilani.
- **Jitsi** : instance **« Chimamanda »** (≤ 30 personnes, partage d'écran),
  mise à disposition gratuitement de petits collectifs.
- **Alignement** : féministe, intersectionnel, autonomie numérique. Très proche
  politiquement.
- **Réserve** : périmètre explicitement **féministe / groupes de femmes** →
  vérifier d'emblée s'ils accepteraient d'héberger un réseau **mixte** de
  bibliothèques. Si non, ils restent un relais précieux (cf. infra).
- **Contact** : via `vedetas.org` / `marialab.org`.

### 2. Escola de Ativismo 🇧🇷 — relais / contact (pas forcément hôte)
- **Qui** : `ativismo.org.br` (`escoladeativismo.org.br`), structure d'appui aux
  mouvements (depuis 2011) — sécurité intégrale, communication, mobilisation.
- **Jitsi** : publie un guide « Jitsi Meet, opção segura » et **promeut**
  l'outil ; n'héberge pas nécessairement une instance ouverte.
- **Pourquoi les contacter** : excellent **relais lusophone** pour être orienté·e
  vers les bons hébergeurs autonomes brésiliens, et pour crédibiliser la démarche.
- **Contact** : `ativismo.org.br/contato`.

### 3. Actantes 🇧🇷 — à vérifier
- Collectif d'**action directe pour la communication libre** dans les réseaux.
  Aligné. Possible hôte ou relais — instance Jitsi à confirmer en direct.

## TIER 2 — Militant européen, capacité confirmée (langues du réseau)

### 4. Autistici/Inventati 🇮🇹 — ✅ actif, instance publique
- **Qui** : `autistici.org` — collectif tech militant italien **historique**.
- **Jitsi** : **`vc.autistici.org`** (cliquer « Go »). ~35 connexions max.

  **italophone** (passerelle pour les biblios italiennes).
- **Contact** : via `autistici.org` (page services / vc).

### 5. systemli.org 🇩🇪 — ✅ actif, instance publique

- **Jitsi** : **`meet.systemli.org`**. Adapté aux **petits groupes (3-15)**.
  Positionné « infrastructure solidaire pour actions solidaires ».
- **Alignement** : fort. **Germanophone**.
- **Contact** : via `systemli.org` (page service Meet).

### 6. immerda.ch 🇨🇭 — à vérifier (Jitsi ?)

## TIER 3 — Libre / CHATONS (France, neutre-libre, fiable)

### 7. Picasoft 🇫🇷 — CHATONS, Jitsi
- `picasoft.net` — CHATON associatif (UTC Compiègne). Propose Jitsi (+ Mumble,
  Mattermost, pads). Libriste, pas explicitement « militant » mais solidaire.

### 8. Framatalk 🇫🇷 — ✅ actif (mais philosophie « décentralisez »)
- `framatalk.org` — instance Jitsi de **Framasoft**. **NON fermée** (préservée
  parmi les services maintenus, contrairement à ce qu'on pouvait croire).
- **Mais** : Framasoft pousse activement vers les **petits hébergeurs locaux /
  CHATONS** plutôt que de centraliser chez eux → bon **dépannage public**, peu
  probable comme hôte dédié permanent. À voir comme filet, pas comme cible.

### 9. Annuaire CHATONS — porte d'entrée à exploiter
- `chatons.org`, filtrer par service **« visioconférence / Jitsi Meet »**.
  Membres à enumérer/contacter : **Infini** (Brest), **Aquilenet** (Bordeaux,
  FAI associatif), **Chapril** (April), etc.
